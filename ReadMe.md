# Jojo Beauty Bar Website

## Project Overview

Jojo Beauty Bar is a fictional beauty business website designed to provide users with information about beauty services and allow them to submit an appointment request.

The website focuses on creating a clean, elegant and welcoming online presence for the business.

## Website Features

The website includes the following pages and features:

* Home page introducing Jojo Beauty Bar
* About page describing the business, mission, vision and values
* Services page displaying available beauty services
* Booking page with an appointment request form
* Contact page with business contact information
* Navigation menu linking all main pages
* Service images for visual presentation
* Responsive styling for different screen sizes
* Booking form validation and submission confirmation
* Footer information across the website

## Services

The website presents the following services:

* Acrylic Manicures
* Gel Manicures
* Pedicures
* Lash Extensions
* Eyebrow Shaping
* Makeup Application

## How to View the Website

Open `homepage.html` in a web browser to access the website.

The navigation menu can then be used to move between the different pages.
